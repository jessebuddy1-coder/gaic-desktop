What GAIC actually checks

Four signals, ordered by how much they prove

  1. Signed creation records (C2PA) A cryptographic manifest is the only signal that can name a generator outright. When one is present and validates, it leads the result.
  2. Camera metadata, cross-checked Make, lens, exposure and timestamps are graded on whether they agree with each other. Every field can be edited, so this supports an investigation rather than settling it.
  3. How the file was written Encoder and container structure can show a file was re-saved and its origin lost. A rewritten container is not itself an AI signal.
  4. The pixel model, as supporting evidence Shown as a separate band, never as the headline and never as a probability. New tools and edited files can fool any detector.

A scan is a lead, not proof. Nothing you choose is uploaded for this quick check.

Straight answers

What an AI photo check can tell you

Can this prove an image was generated by AI?

No. Detectors can be wrong, especially after screenshots, resizing, filters, or new generator releases. Use the signal as one clue and verify the source.

Is my photo uploaded?

No. This page loads the model only after you start a check, then analyzes the selected JPEG or PNG on your device.

How sure is the result?

Every check ends with a lean — likely AI-generated or likely real — and a confidence level. High, medium, and low confidence were set on generators and image sources the model never trained on. A low-confidence lean is a close call, so check the source before relying on it.
