# GAIC on-device model assets

The shipping app includes `aicheck-ai-image-v3-fp16.onnx`, GAIC Image Model
v3. It is the GAIC Image Model v2 network with the same 41 MB, MIT-licensed
weights derived from the Community Forensics 224 model, plus a `features`
output that the image decision head in `../image-head.js` reads. It runs
entirely on the device. Its exact source revision, checksum, preprocessing,
labels, decision head, measured results, and limitations are recorded in
[AICHECK-IMAGE-MODEL.md](AICHECK-IMAGE-MODEL.md). The v2 file,
`aicheck-ai-image-v2-fp16.onnx`, is no longer loaded.

The decision head turns the model's reading into an estimated AI likelihood, a
lean, and a confidence level measured on held-out images. It is an estimate
from the pixels, not an authorship finding or proof that an image is
authentic. Do not remove its limitations from the interface or market it as a
lie detector.

## Replacing the model

Any replacement must be reviewed before it ships. Add an ONNX image classifier
to this directory and update `../model-config.js` with the exact input size,
normalization, AI-class index, source revision, and a new checksum. A new
network also needs a retrained and recalibrated `../image-head.js`. Then update
the model card, attribution, `../test/model-smoke.mjs`,
`../test/model-benchmark.mjs`, and a reproducible, licensed real-world
evaluation set together.

`model-benchmark.mjs` is an offline regression benchmark over 20 pixel fixtures
generated by original deterministic code. It can catch runtime, class-index,
preprocessing, score-distribution, and warning-policy drift. Its labels describe
fixture families; none are camera-photo or generative-model ground truth.
Therefore it does **not** measure detector accuracy. The decision head's
measured accuracy is in the model card.

The loader assumes a single-image NCHW float32 classifier and discovers its
actual input/output tensor names from the model. It applies a simple resize to
the configured square input size; choose preprocessing that matches the model.
